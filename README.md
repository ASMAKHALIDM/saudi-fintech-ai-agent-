Real-time crypto risk monitoring powered by FinBERT NLP + CoinMarketCap live data

What It Does
This AI agent monitors 5 major crypto assets (BTC, ETH, BNB, SOL, AVAX) in real time by:
Fetching live prices from CoinMarketCap API
Scraping news headlines from RSS feeds (CoinDesk, CoinTelegraph, Decrypt) — no API key needed
Analyzing sentiment using FinBERT, a financial domain NLP model
Generating risk alerts (CRITICAL / WARNING / WATCH / STABLE)
Producing executive briefs and visual dashboards
Auto-refreshing every 30 minutes in a continuous loop
